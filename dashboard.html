How to Use AI Accessibility Auditor

Welcome to the AI Accessibility (WCAG 2.1 AA) & UI Regression Auditor. This platform provides continuous, deterministic DOM and CSS contrast verification combined with AI-assisted cognitive remediation.

1. Web Dashboard Usage (Browser)

  1. Select Test Page: Click on any page in the left sidebar (e.g. 01_ecommerce_checkout.html) to load its live rendered interface in the center iframe.
  2. Inspect Violations: Review the detected WCAG barriers on the right side. Each card shows the standard Rule ID, exact DOM CSS selector, and root cause explanation.
  3. Copy Fixes: Click the Copy Fix button to grab the drop-in compliant HTML replacement.
  4. Trigger Re-Audit: Click ⚡ Run Live Audit in the header to re-execute the engine against the files dynamically.

2. CLI Usage (Terminal)

You can run the deterministic audit engine directly from your command line:

python main.py

This generates a formatted CLI report and writes structured results to output/initial_audit_report.json.

3. Active WCAG Rules Covered

  • WCAG-1.1.1 (Level A): Missing Image Alt Text
  • WCAG-1.3.1 (Level A): Form Input Missing Labels / Placeholder Only
  • WCAG-1.4.3 (Level AA): Insufficient Color Contrast (< 4.5:1 for text)
  • WCAG-1.3.1 (Level A): Heading Hierarchy Skips (e.g. h1 → h4)
  • WCAG-3.1.1 (Level A): Missing Document Language (<html lang="en">)
  • WCAG-4.1.2 (Level A): Invalid Interactive ARIA (e.g. fake button without tabindex)
  • WCAG-2.4.4 (Level A): Ambiguous Link Text ("Click here", "Read more")
  • WCAG-2.4.7 (Level AA): Focus Outline Suppressed (outline: none)
