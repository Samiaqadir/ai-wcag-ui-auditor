#3 • WCAG-1.3.1
Critical Confirmed Defect

Missing Form Input Label

Selector: #cardholder-name

Form control <input> lacks an accessible programmatic label (<label for='...'>, wrapping label, or aria-label). Relying solely on placeholder='Cardholder Full Name' violates WCAG 3.3.2 because placeholders disappear on user input and are not reliably announced by all screen readers.

QA Reviewer Note: Confirmed Defect: Meets WCAG AA failure criteria; ticket filed in sprint backlog for frontend remediation.

🔴 Non-Compliant HTML (Before)
