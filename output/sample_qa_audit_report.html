#3 WCAG-1.3.1

Missing Form Input Label

Critical ● Confirmed Defect
Target DOM Selector: #cardholder-name

Accessibility Barrier: Form control <input> lacks an accessible programmatic label (<label for='...'>, wrapping label, or aria-label). Relying solely on placeholder='Cardholder Full Name' violates WCAG 3.3.2 because placeholders disappear on user input and are not reliably announced by all screen readers.

Remediation Strategy: <label for="cardholder-name">Field Label</label> or aria-label="Field Label"
